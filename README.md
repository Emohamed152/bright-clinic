# مركز برايت - موقع تجريبي

موقع ثابت (React + Vite) بيتنشر مجانًا على GitHub Pages ولينكه بيفضل شغال على طول من غير ما يعتمد على حد.

**مهم:** ده عرض تجريبي. مفيش سيرفر ولا قاعدة بيانات، وأي حجز بتكتبيه بيظهر على الصفحة بس لحد ما تعملي refresh، ومش بيتبعت ولا بيتحفظ في أي مكان. ماتكتبيش بيانات مرضى حقيقية فيه.

## الخطوات على GitHub Pages (لأول مرة)

1. اعملي حساب على github.com لو معندكيش.
2. من فوق على اليمين اضغطي **+** ثم **New repository**. اكتبي اسم زي `bright-center`، اختاري **Public**، واضغطي **Create repository**.
3. في صفحة الـ repository الجديد اضغطي **uploading an existing file**.
4. فكي الـ zip على جهازك، وافتحي الفولدر. **اسحبي كل اللي جواه** (مش الفولدر نفسه) وارميه في صفحة GitHub. تأكدي إن فولدر `.github` اترفع كمان (لو مش باين عندك في الويندوز، فعّلي Show hidden files). اضغطي **Commit changes**.
5. روحي **Settings** ثم **Pages**. في **Source** اختاري **GitHub Actions**.
6. روحي تبويب **Actions**. هتلاقي عملية اسمها "Deploy to GitHub Pages" شغالة. استني دقيقة أو اتنين لحد ما تبقى علامة صح خضرا.
7. اللينك بتاعك هيبقى: `https://اسم-المستخدم.github.io/bright-center/` (هتلاقيه كمان في Settings ثم Pages).

أي تعديل بتعمليه في الملفات على GitHub (زر القلم على الملف) بيتنشر لوحده بعد دقيقة.

## لو عايزة تشغليه على جهازك

1. نزلي Node.js من nodejs.org (نسخة LTS).
2. افتحي الفولدر في Terminal واكتبي:
   - `npm install`
   - `npm run dev` ويفتح على `http://localhost:5173`

## التعديل

- `src/App.tsx`: الصفحات والكلام العربي والخدمات والمواعيد.
- `src/style.css`: الألوان والشكل.
- `src/photos`: الصور (مولدة بالذكاء الاصطناعي). بدليها بصور المركز الحقيقية بنفس الأسماء.
