# مركز برايت - نظام الحجز وإدارة المركز

- **صفحة المرضى** (`/`): الخدمات والأسعار وطلب حجز. المريض مش بيشوف أي بيانات تانية.
- **صفحة الموظفين** (`/#/staff`): تسجيل دخول، الحجوزات، ملفات المرضى، المدفوعات، الخدمات والأسعار، حسابات الموظفين.
- الحجز اللي بيبعته المريض بيتسجل "طلب جديد" في قاعدة البيانات، والموظف بيأكده (الصفحة بتتحدث لوحدها كل 20 ثانية).
- **فرونت إند**: React + Vite (الفولدر الرئيسي). **باك إند**: Node.js + Express + MongoDB (فولدر `backend`).

> ⚠️ **بيانات المرضى حساسة.** قبل ما تحطي بيانات مرضى حقيقية: اتأكدي من قواعد حماية البيانات الشخصية في مصر، واخدي موافقة المرضى لو لازم، ودخلي بيانات تجربة بس لحد ما تجربي كل حاجة. استخدمي باسوردات قوية، وماتشاركيش حساب الدخول مع حد.

---

## الخطوة 0: رفع الملفات على GitHub

1. افتحي الـ repository (`bright-clinic`) على GitHub.
2. **امسحي فولدر `.github`** القديم لو موجود (كان بيرفع الموقع على GitHub Pages، ومش محتاجينه دلوقتي): افتحي `.github/workflows/deploy.yml` > أيقونة سلة المهملات > Commit.
3. فكي الـ zip، **واسحبي كل اللي جواه** (مش الفولدر نفسه، وفيه فولدر `backend` و`src`) وارميه في صفحة الـ repo (Add file > Upload files)، ودوسي Commit changes. استني لحد ما كل الملفات تترفع.

## الخطوة 1: قاعدة البيانات على MongoDB Atlas

1. اعملي حساب على mongodb.com/cloud/atlas وسجلي دخول.
2. اعملي **Cluster مجاني (Free)**. اختاري منطقة قريبة (أوروبا مثلا).
3. هيطلب منك **Database User**: اكتبي اسم مستخدم وباسورد **حروف وأرقام بس** (من غير رموز). **الباسورد ده سر، ماتبعتيهوش لأي حد.**
4. من **Network Access** > Add IP Address > **Allow access from anywhere** (`0.0.0.0/0`). لازم كده لأن Vercel مالوش IP ثابت. الأمان هنا جاي من الباسورد القوي.
5. من **Database > Connect > Drivers** انسخي الـ **connection string**. شكله كده:
   `mongodb+srv://اسم:<password>@cluster0.xxxx.mongodb.net/?retryWrites=true&w=majority`
   - بدلي `<password>` بالباسورد بتاعك.
   - حطي اسم قاعدة البيانات `clinic` قبل علامة `?`، فيبقى: `...mongodb.net/clinic?retryWrites=true&w=majority`
   - **ده سر. هتحطيه في Vercel بس (الخطوة 2). ماتبعتهوش في أي شات ولا تكتبيه في أي ملف.**

**حدود النسخة المجانية:** مساحة 512 ميجا، موارد مشتركة، ومفيش نسخ احتياطي تلقائي (Atlas بيقدم نسخ احتياطي بسعر بسيط كخيار، راجعي صفحة Atlas). للمرضى الحقيقيين فعّلي النسخ الاحتياطي أو انتقلي لخطة مدفوعة.

## الخطوة 2: الباك إند على Vercel

1. ادخلي vercel.com وسجلي بحساب GitHub.
2. **Add New > Project** > اختاري الـ repo `bright-clinic` > Import.
3. في **Root Directory** دوسي Edit واختاري **`backend`**. الـ Framework Preset: **Other**.
4. افتحي **Environment Variables** وضيفي (الأسماء بالظبط):
   - `MONGODB_URI` = الـ connection string من الخطوة 1 (سر)
   - `JWT_SECRET` = أي جملة عشوائية طويلة **40 حرف أو أكتر** حروف وأرقام (سر، مش لازم تحفظيها)
   - `SETUP_CODE` = كود من اختيارك **8 حروف على الأقل** (هتحتاجيه مرة واحدة)
   - `FRONTEND_ORIGIN` = سيبيه فاضي دلوقتي، هنكتبه في الخطوة 4
5. دوسي **Deploy**. لما يخلص هتلاقي رابط زي `https://xxxx.vercel.app`. افتحي `https://xxxx.vercel.app/api/health` ولازم يظهر: `{"ok":true,"configured":true}`. لو `configured` بـ false يبقى متغير ناقص (JWT_SECRET لازم 40 حرف+).
6. انسخي رابط الباك إند ده (من غير `/` في الآخر).

## الخطوة 3: الفرونت إند على Vercel

1. **Add New > Project** تاني > نفس الـ repo > Import.
2. **Root Directory** سيبيه الأساسي (`./`). الـ Framework هيطلع **Vite** لوحده.
3. في **Environment Variables** ضيفي: `VITE_API_URL` = رابط الباك إند من الخطوة 2 (ده مش سر).
4. **Deploy**. هتاخدي رابط الموقع، زي `https://bright-clinic.vercel.app`. ده اللينك اللي بتديه للمرضى.

## الخطوة 4: ربط الاتنين

1. ارجعي لمشروع **الباك إند** في Vercel > Settings > Environment Variables > عدلي `FRONTEND_ORIGIN` = رابط الفرونت إند (من غير `/` في الآخر)، مثلا `https://bright-clinic.vercel.app`.
2. **لازم Redeploy**: Deployments > آخر واحد > ⋯ > Redeploy.

## الخطوة 5: أول حساب للدكتور

1. افتحي: `رابط-الموقع/#/setup` (مثال: `https://bright-clinic.vercel.app/#/setup`).
2. اكتبي كود الإعداد (`SETUP_CODE`)، اسمك، إيميلك، وباسورد قوي (10 حروف على الأقل). الصفحة دي بتشتغل **مرة واحدة بس**، وبعد ما يتعمل أول حساب بتتقفل.
3. بعدها امسحي `SETUP_CODE` من Vercel (اختياري، أحسن للأمان).
4. سجلي دخول من `رابط-الموقع/#/staff`.
5. من تبويب **الخدمات** ضيفي الخدمات والأسعار الحقيقية (بتظهر للمرضى). من **الموظفين** ضيفي حساب الاستقبال.

## تجربة سريعة

افتحي الرابط من موبايل تاني، ابعتي طلب حجز تجريبي (بيانات وهمية)، وارجعي للوحة الموظفين: هتلاقيه في "طلبات جديدة". دوسي تأكيد، وهيتعمل ملف للمريض في تبويب المرضى.

## الأمان (إيه اللي متعمل)

- المريض (من غير تسجيل دخول) يقدر بس: يقرا الخدمات والأسعار، ويبعت طلب حجز. مفيش أي طريقة يقرا بيانات حجوزات أو مرضى أو مدفوعات.
- كل بيانات الموظفين محمية بتسجيل دخول (توكن 12 ساعة). الدور "استقبال" مايقدرش يعدل الخدمات أو الموظفين. الموظف الموقوف بيتقفل عليه فورًا.
- باسوردات متشفرة، وقفل 15 دقيقة بعد 5 محاولات غلط، وحد للطلبات المتكررة ضد السبام، وCORS لموقعك بس.
- الباسوردات والأسرار موجودة في Vercel/Atlas بس، مش في الكود ولا في GitHub.

## حدود لازم تعرفيها

- **Vercel المجانية (Hobby) للاستخدام الشخصي وغير التجاري بس**، حسب شروط Vercel. مركز علاج حقيقي = استخدام تجاري، فهتحتاجي خطة **Pro** المدفوعة قبل الاستخدام الفعلي.
- مفيش دفع أونلاين: "المدفوعات" تسجيل لللي المريض دفعه (كاش/كارت) بإيدك.
- مفيش إشعارات (SMS/واتساب) للمريض: المركز هو اللي بيتصل لتأكيد الحجز.
- الحجز "طلب"، مش بيمنع حجز نفس الميعاد مرتين. الموظف بيراجع وبيأكد.
- مفيش نسخ احتياطي تلقائي في Atlas المجاني (شوفي الخطوة 1).

## لو عايزة تجربيه على جهازك

1. نزلي Node.js (nodejs.org).
2. باك إند: `cd backend` ثم `npm install` ثم `npm test` (بيشغل اختبارات بقاعدة بيانات مؤقتة).
3. فرونت إند: في الفولدر الرئيسي `npm install` ثم `npm run dev`.

## التعديل

- `src/Public.tsx`: صفحة المرضى. `src/Staff.tsx`: لوحة الموظفين. `src/style.css`: الشكل. `src/photos`: الصور (مولدة بالذكاء الاصطناعي، بدليها بصور المركز).
- `backend/src/app.js`: كل الـ API. `backend/src/models.js`: شكل البيانات.
